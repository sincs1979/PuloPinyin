部落输入法（macOS）

不要双击浏览器下载栏里的文件。从 GitHub 直接下的 .pkg / .dmg / 安装.command 会被系统隔离。

推荐（终端一条命令，不会被隔离）：

curl -fsSL https://raw.githubusercontent.com/sincs1979/PuloPinyin/main/安装-macos.sh | bash

若已经打开本磁盘映像，终端执行：

xattr -cr /Volumes/部落输入法 && open "/Volumes/部落输入法/安装.command"

装好后：系统设置 → 键盘 → 输入法 → 编辑… → 左下角 +，搜索「部落」或「Buluo」。
不要把应用拖进「应用程序」文件夹。
